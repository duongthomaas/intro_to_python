# Lunch and Learn: Intro to Python

A beginner-friendly introduction to Python fundamentals, designed for our Lunch and Learn session at TIL.

## Topics Covered

- **Variables** - Store and use data in your programs
- **Lists** - Work with collections of items
- **Dictionaries** - Organize data with key-value pairs
- **If Statements** - Make decisions in your code
- **For Loops** - Iterate through collections
- **While Loops** - Repeat tasks until a condition is met
- **Try/Except Blocks** - Handle errors gracefully
- **Functions** - Create reusable blocks of code
- **Packages and Libraries** - Extend Python's capabilities

## How to Use

Each topic includes:

- Clear explanations of concepts
- Practical code examples
- Hands-on exercises to practice

## Getting Started

Open the main document and follow along with the examples. Try running the code snippets and complete the exercises to reinforce your learning.

## Prerequisites

- Python installed on your machine
- A text editor or IDE
- Enthusiasm to learn!

Happy coding! 🐍
